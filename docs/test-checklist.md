| 잘못된 데이터 구조 | 정답 번호 9를 감지하고 기본 문제로 복구 | 통과 |

| 파일 쓰기 실패 모의 검증 | PermissionError 발생 시 안내 후 False 반환 | 통과 |

## 검증 방법과 범위

- 저장 파일 없음, 손상된 JSON, 빈 목록 검증은 별도 테스트 폴더에서 수행했다.
- 잘못된 정답 번호 검증은 원본 폴더에서 수행되어 원본 게임 데이터가 초기화됐다.
- 초기화 전에 확인한 점수와 기록의 유지 결과는 당시 실행 화면으로 확인했다.
- 파일 읽기·쓰기 실패는 unittest.mock으로 Path.open에서 PermissionError를 발생시키는 방식으로 확인했다.
- 모의 검증에서는 실제 파일 권한을 변경하지 않았다.
- 모든 가능한 입력과 운영체제 오류를 검증한 것은 아니다.
